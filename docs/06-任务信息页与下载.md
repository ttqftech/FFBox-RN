## 6.2 库选型

### 6.2.1 文件下载与访问：`expo-file-system`

**理由**：FFBox 在网页/electron 用 `<a download>` / `nodeBridge.downloadFile`。RN 无浏览器下载，需要用文件系统 API 把响应流写入本地。`expo-file-system` 是 Expo 官方、跨端统一的文件 API。

```bash
pnpm exec expo install expo-file-system expo-permissions
```

```ts
import * as FileSystem from 'expo-file-system';
import * as MediaLibrary from 'expo-media-library'; // 可选：保存到相册

// 下载到应用缓存目录
const target = `${FileSystem.cacheDirectory}${baseName}`;
const res = await FileSystem.downloadAsync(url, target, {
  headers: { Cookie: `sessionId=${sessionId}` },
});
// 需要用户可见时，再拷贝到共享目录/相册并请求权限
```

**替代方案**：`react-native-blob-util`（也支持下载 + 状态回调，步骤4已引入）；`expo-sharing` 分享到系统。

### 6.2.2 权限：`expo-permissions` / `expo-media-library`

**理由**：Android 13+ 写外部存储需 `MediaStore` 权限；iOS 保存到相册需 `photo` 权限。`expo-media-library` 提供 `requestPermissionsAsync`。

```ts
const { status } = await MediaLibrary.requestPermissionsAsync();
if (status !== 'granted') { Alert.alert('需要相册权限才能保存'); return; }
```

**替代方案**：仅下载到应用私有目录（`documentDirectory`）则无需权限；「保存到相册」才需要 media-library 权限。

### 6.2.3 run 切换：自绘船型按钮（组合箭头）

参考 `TaskInfoTitle.vue` 的 `RockerSwitch`。RN 无现成 RockerSwitch，可用两个 `Pressable`（◀ ▶）+ 中间 label 自绘，或 `@ronradtke/react-native-rocker-switch`（维护一般，建议自绘）。

## 6.3 页面结构（`task-info.tsx`）

```
[返回]        任务信息        [操作按钮 ◀▶]   ← 操作按钮仅最新 run 显示
[◀ ] 第 N 次运行 / 已扫描媒体信息 [ ▶]         ← 船型切换
[基本信息] (backgroundProgress + 任务名 + paraArea + dashboardArea)
[命令参数] (可折叠，纯文本 paraArray)
[输出日志] (可折叠，纯文本 cmdData，自动滚动到底)
[输出文件] (outputFiles 列表，点击下载)
```

### 6.3.1 入口与数据

- 从任务列表点击进入（非选择模式），路由参数携带 `taskId`。
- 任务数据来自 `appStore.currentServer.data`，实时监听（步骤2已建立）。
- 当前 run：`task.runs[task.selectedRunIndex]`。

```tsx
// src/app/task-info.tsx
const { taskId } = useLocalSearchParams<{ taskId: string }>();
const snap = useSnapshot(appStore);
const task = snap.currentServer?.data.tasks.find(t => t.id === Number(taskId));
const run = task?.runs[task.selectedRunIndex];
const isLatest = task?.selectedRunIndex === (task?.runs.length ?? 1) - 1;
```

### 6.3.2 标题栏操作按钮

参照 `handlePauseNremove`（仅最新 run 显示）：

```tsx
const handleAction = () => {
  if ([TaskStatus.running, TaskStatus.paused_queued].includes(task.status)) {
    entity.taskPause([task.id]);
  } else if ([TaskStatus.idle_queued, TaskStatus.paused, TaskStatus.stopping, TaskStatus.finished, TaskStatus.error].includes(task.status)) {
    entity.taskReset([task.id]);
  } else if (task.status === TaskStatus.idle || task.status === TaskStatus.initializing) {
    // 见下方删除按钮
  }
};
```

- **起点**: idle 状态点「开始」→ `entity.taskStart([task.id])`。
- **运行中**: 参考 `handlePauseNremove`（暂停/重置）。
- **额外删除按钮**: `idle`/`finished`/`error` 状态下，标题栏左侧多一个删除按钮 → `appStore.deleteTasks([task.id])`（参考 TaskItem 菜单）。

### 6.3.3 船型切换 run

```tsx
const canPrev = (task?.selectedRunIndex ?? 1) > 1;
const canNext = task ? task.selectedRunIndex < task.runs.length - 1 : false;
const goPrev = () => { task!.selectedRunIndex--; };
const goNext = () => { task!.selectedRunIndex++; };
```

> 修改 `selectedRunIndex` 后 `useSnapshot` 自动触发重渲染（valtio 响应式）。

### 6.3.4 基本信息模块

复用步骤3的 `TaskItem` 拆出来的展示原子（或直接内联）：
- `backgroundProgress`：`run.dashboard_smooth.progress` 比例填充。
- 第一行：任务名。
- 第二行（paraArea）：时长/容器/规格/视频/音频 转换信息（参考 TaskItem `handleParaAreaMouseEnter` 内容）。
- 第三行（dashboardArea）：时间/帧/码率/速度/输出大小/预计剩余时间/读取总量/校验总量/上传总量/进度（参考 TaskItem dashboardArea 与 `transferInfo`）。

> 建议把 TaskItem 的「dashboard 计算」抽成 `useDashboard(task)` hook，任务条与任务信息页共用，避免重复。

### 6.3.5 命令参数模块

纯文本展示 `run.paraArray.join(' ')`（参考 FFmpegLog 的 `cmdText` 当 `cmdDisplay === 'input'` 时）。

```tsx
<ScrollView style={styles.code}>
  <Text selectable style={styles.codeText}>
    {['ffmpeg', ...(run?.paraArray ?? [])].join(' ')}
  </Text>
</ScrollView>
```

### 6.3.6 输出日志模块

纯文本展示 `run.cmdData`，内容变化时自动滚到底（参考 FFmpegLog `watch`）。

```tsx
const scrollRef = useRef<ScrollView>(null);
useEffect(() => {
  scrollRef.current?.scrollToEnd({ animated: false });
}, [run?.cmdData]);
```

### 6.3.7 输出文件模块

展示 `run.outputFiles` 列表。仅 `[TaskStatus.finished, TaskStatus.error].includes(run.status)` 且列表非空时允许点击下载（参考 MediaInfo `openFile`）。

## 6.4 下载到本地

```ts
// src/logic/downloadManager.ts
import * as FileSystem from 'expo-file-system';
import * as MediaLibrary from 'expo-media-library';

export async function downloadOutputFile(server, filePath, baseName) {
  const url = `http://${server.ip}:${server.port}/download/${filePath}`;
  const target = `${FileSystem.documentDirectory}${baseName}`;
  const res = await FileSystem.downloadAsync(url, target, {
    headers: { Cookie: `sessionId=${server.sessionId}` },
  });
  if (res.status !== 200) throw new Error(`下载失败: ${res.status}`);
  // 保存到相册（可选，需权限）
  const perm = await MediaLibrary.requestPermissionsAsync();
  if (perm.granted) await MediaLibrary.saveToLibraryAsync(res.uri);
  return res.uri;
}
```

> **平台差异**：RN 无浏览器 `<a download>`。下载先落到应用私有目录；「保存到相册」需 `expo-media-library` 权限。优先级：先实现「下载到私有目录并可打开」，相册保存作为增强。

## 6.5 可运行验收

1. 从任务列表点击进入任务信息页，标题栏显示返回/任务信息/操作按钮。
2. 船型按钮能切换第 N 次 run，各模块数据随之切换。
3. 基本信息模块展示进度条 + 任务名 + 参数信息 + dashboard（时间/帧/码率/速度/大小/剩余时间/读取/校验/上传/进度）。
4. 命令参数/输出日志以纯文本展示，日志自动滚到底。
5. 输出文件模块：成功完成后点击可下载到本地；未完成时点击提示「转码完成后才可下载」。
6. 下载前请求文件读写权限，确认后才继续。
7. idle 点「开始」能启动；运行中点操作按钮暂停/重置；idle/finished/error 有删除按钮。
