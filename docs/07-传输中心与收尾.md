## 7.2 库选型

### 7.2.1 后台任务：`expo-background-task`（可选）

**理由**：需求「上传下载支持后台运作」。Expo 托管环境用 `expo-background-task` 注册后台任务；但注意 expo-background-task 对网络上传的场景支持有限（更适合短时任务）。

```bash
npx expo install expo-background-task
```

```ts
import * as BackgroundTask from "expo-background-task";
BackgroundTask.defineTask("upload-loop", async () => {
  // 推动上传队列（需在 foreground 已初始化好队列）
  await pumpUploadQueue();
});
```

**替代方案**：`react-native-background-fetch`（更底层）；或**不强制后台**——需求明确「软件被切后台无需手动保活，按默认逻辑」，因此可**先不做真正后台上传**，仅保证切后台时上传暂停、回前台继续，作为 TODO 说明。

参考 TransferCenter UI，做移动端适配。FFBox 有三栏（上传/已选任务上传/下载）切换 + 分片列表。FFa0x 简化为：

│ 点选某文件 → 展开分片列表        │

### 7.3.1 上传文件列表

按 `TransferCenter.vue` 的 `uploadFileList` 计算三阶段进度：

```ts
const uploadFileList = snap.currentServer?.data.uploadFiles.map(f => ({
  fileBaseName: f.fileBaseName,
  taskId: f.taskId,
  status: f.status,
  chunks: f.chunks,
  size: f.size,
  readProgress: f.chunks.reduce((p, c) => p + c.size, 0) / f.size,
  hashProgress: f.chunks.reduce((p, c) => p + (c.hash ? c.size : 0), 0) / f.size,
  uploadProgress: f.chunks.reduce((p, c) => p + c.transferred, 0) / f.size,
})) ?? [];
```

进度条用三色 clip（参考 vue 的 `clipPath: polygon(...)`，RN 用 `clipPath` 支持有限，可用三段绝对定位 View 或 `overflow` 遮罩近似）。

### 7.3.2 分片列表

选中文件后展示 `chunks`，每片显示 `hash` + `transferred/size` 进度；error 状态标红。

## 7.4 后台保活与掉线重连

### 7.4.1 后台默认逻辑

需求明确「切后台无需手动保活，按默认逻辑」。即：
- 不上传时，切后台 OS 可能挂起 JS，事件监听自动暂停。
- 回前台时，React Native 重新激活，`useAppState` 监听 `active` 事件。

```ts
// src/logic/keepAlive.ts
import { AppState } from "react-native";
import { reconnectOnce } from "./serviceBridge";

export function setupKeepAlive() {
  AppState.addEventListener("change", (state) => {
    if (state === "active") {
      // 复活时若掉线，自动重试 1 次
      if (isDisconnected()) reconnectOnce();
    }
  });
}
```

### 7.4.2 掉线检测与 UI

- 事件流中断（WebSocket 断/HTTP 探活失败）→ `server.entity.status = Disconnected`。
- 主界面任务列表隐藏，画面中心显示「掉线」+「重试」按钮（参考需求 3.4）。

```tsx
{disconnected ? (
  <View style={styles.center}>
    <Text>连接已断开</Text>
    <Button title="重试" onPress={() => reconnect() } />
  </View>
) : (
  <TaskList />
)}
```
