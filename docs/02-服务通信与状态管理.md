## 2.2 库选型

### 2.2.1 响应式状态：`valtio`

**理由**：
- Proxy 响应式，`useSnapshot` 读取即响应，**写法与 Vue/Pinia 几乎一致**（赋值即更新），最符合「禁 redux、要求响应式」的约束。
- 无 action/selector 样板，避免过度抽象。

```bash
pnpm install valtio
```

```ts
// src/stores/appStore.ts
import { proxy } from 'valtio';
import { Server, ServerData } from '../types';

export const appStore = proxy({
  servers: [] as Server[],
  currentServerId: undefined as string | undefined,
  selectedTask: new Set<number>(),
  // ... 其他状态
});

// 组件内读取（响应式）
import { useSnapshot } from 'valtio';
const snap = useSnapshot(appStore);
// snap.servers, snap.selectedTask 变化会自动重渲染
```

**替代方案**：
- `zustand`：订阅式，也轻量，但需要手动 `selector` + `useShallow`，不像 Pinia 直观。
- `mobx`：`makeAutoObservable` 也接近 Vue，但装饰器/转换配置偏重。

> **结论：选 valtio**，因为它是对「Pinia 迁移」最平滑的。

### 2.2.2 事件总线：npm `events`

**理由**：`ServiceBridge` 需要 `EventEmitter` 语义，RN 无 Node `events`，但 npm 的 `events` 包提供纯 JS 的 EventEmitter polyfill，可直接在 RN 使用，且 `on/off/emit/removeAllListeners` 同签名，改动最小。

`events` 已在 `package.json`（`"events": "^3.3.0"`），无需再安装：

```ts
// src/bridges/emitter.ts
import EventEmitter from 'events';
export const emitter = new EventEmitter();
```

**替代方案**：`mitt`（更主流）、`eventemitter3`；也可自写 20 行 `on/off/emit/removeAllListeners`。

### 2.2.3 哈希：`expo-crypto`（沿用步骤 1）

用于登录 SHA256、上传 SHA1。

## 2.3 ServiceBridge 移植要点

直接复制 `serviceBridge.ts`，改动点：

1. `import EventEmitter from 'events'` → ServiceBridge 继承 EventEmitter（npm `events` 包，纯 JS polyfill），保留 `on/off/emit/removeAllListeners` 同签名。
2. `CryptoJS.SHA256(password)` → `expo-crypto` 的 `digestStringAsync`（因 `connect` 是 async，可 await）。
3. `WebSocket` 用 RN 内置的（全局可用）。
4. 保留全部 HTTP 方法（`taskAddBatch`、`setParameters`、`getTaskList`、`queueStart` 等）。

```ts
// src/bridges/serviceBridge.ts（改动后骨架）
import EventEmitter from 'events';

export class ServiceBridge extends EventEmitter {
  public ws: WebSocket | null = null;
  public ip?: string; public port?: number;
  public username?: string; public password?: string;
  public status = ServiceBridgeStatus.Idle;
  public sessionId?: string;
  public permissions: Permission[] = [];
  public reconnectAttempted = false;   // 仅意外掉线自动重连用；手动断开不触发重连
  private manualDisconnect = false;    // 手动断开标记：disconnect() 置 true，ws.onclose 据此判断不掉线

  // on/off/emit/removeAllListeners 由 EventEmitter 继承，签名不变

  async connect(ip?, port?, username?, password?) { /* 原逻辑，SHA256 换 expo-crypto */ }
  disconnect() { this.manualDisconnect = true; this.ws?.close(); }
  // ... 所有 HTTP 方法原样保留
}
```

## 2.4 Store 结构（对齐 appStore）

```ts
// src/stores/appStore.ts
import { proxy } from 'valtio';
import { Server, ServerData, UITask, UploadFile, DownloadFile } from '../types';
import { ServiceBridge } from '../bridges/serviceBridge';
import { defaultParams } from '../common/defaultParams';
import { OutputParams } from '../common/types';

function newServerData(id: string): ServerData {
  return {
    id, name: '未连接', tasks: [], taskIdToIndex: new Map(),
    notifications: [], uploadFiles: [], downloadFiles: [],
    ffmpegInfo: { version: '', scanning: false, videoEncodersCount: 0, audioEncodersCount: 0, muxersCount: 0, demuxersCount: 0, filtersCount: 0 },
    version: '', totalCount: 0, workingStatus: 'idle', progress: -1, asyncList: [],
  };
}

export const appStore = proxy({
  servers: [] as Server[],
  currentServerId: undefined as string | undefined,
  selectedTask: new Set<number>(),
  isAllSelected: false,
  // 移动端无全局参数概念，保留位置但注释（globalParams/presetName/availablePresets）
  // globalParams: JSON.parse(JSON.stringify(defaultParams)) as OutputParams,
  // presetName: '',
  // availablePresets: [] as string[],

  get currentServer() {
    return this.servers.find(s => s.data.id === this.currentServerId);
  },
  getTaskById(taskId: number): UITask | undefined {
    const d = this.currentServer?.data; if (!d) return undefined;
    const i = d.taskIdToIndex.get(taskId);
    return i !== undefined ? d.tasks[i] : undefined;
  },
  addServer() {
    const id = randomString(6);
    this.servers.push({ data: newServerData(id), entity: new ServiceBridge() });
    this.currentServerId = id;
  },
  // ... 其余 action（initializeServer 等）见下
});
```

> **注意**：valtio 的 `proxy` 支持 getter（`currentServer`），但 getter 内用到的字段在读取时被追踪。`Set`/`Map` 在 valtio 里可直接用，但组件要用 `useSnapshot` 读取以触发更新。

### 2.4.1 初始化连接（移自 `appStore.initializeServer`）

事件监听改为本地事件，其余逻辑保留：

```ts
async initializeServer(serverId, ip, port, username, password, retryCount = 0) {
  const server = this.servers.find(s => s.data.id === serverId)!;
  const entity = server.entity;
  const bind = () => {
    entity.on('connected', () => {
      server.data.name = ip;
      server.data.tasks = []; server.data.taskIdToIndex = new Map();
      this.updateServerProperties();
      this.updateTaskList(0);
      this.updateNotifications();
    });
    entity.on('disconnected', (manual) => {
      // 手动断开（manual=true）不自动重连；仅意外掉线（manual=false）自动重连 1 次
      if (!manual && !entity.reconnectAttempted) {
        entity.reconnectAttempted = true;
        this.reConnectServer(serverId);
      }
    });
    entity.on('error', (reason) => {
      if (!retryCount || reason.includes('连接失败')) { /* 最终失败 */ }
      else setTimeout(() => this.initializeServer(serverId, ip, port, username, password, retryCount - 1), 150);
    });
    entity.on('tasklistUpdate', d => { handleTasklistUpdate(server, d); });
    entity.on('taskUpdate', d => { handleTaskUpdate(server, d.taskId, d.task); });
    entity.on('cmdUpdate', d => handleCmdUpdate(server, d.taskId, d.runIndex, d.content, d.append));
    entity.on('progressUpdate', d => handleProgressUpdate(server, d.taskId, d.runIndex, d.time, d.status));
    entity.on('notificationUpdate', d => handleNotificationUpdate(server, d.notificationId, d.notification));
    entity.on('workingStatusUpdate', d => handleStatusUpdate(server, d));
    entity.on('asyncListUpdate', d => { server.data.asyncList = d.list; });
  };
  bind();
  entity.connect(ip, port, username, password);
}
```

## 2.5 eventsHandler 与 dashboardCalc 移植

`eventsHandler.tsx` 与 `dashboardCalc.ts` 基本**逻辑不变**，仅终止依赖：

## 2.6 主界面最简列表（验证数据流）

本步主界面只要能显示「任务标题 + 进度条」即可，完整 UI 在步骤 3。

```tsx
// src/app/(main)/index.tsx（最简版）
import { useSnapshot } from 'valtio';
import { appStore } from '../../stores/appStore';
import { FlatList, View, Text, StyleSheet } from 'react-native';

export default function MainScreen() {
  const snap = useSnapshot(appStore);
  const tasks = snap.currentServer?.data.tasks ?? [];
  return (
    <FlatList
      data={tasks}
      keyExtractor={t => String(t.id)}
      renderItem={({ item }) => {
        const run = item.runs[item.runs.length - 1];
        const pct = Math.round((run?.dashboard_smooth.progress ?? 0) * 100);
        return (
          <View style={styles.row}>
            <Text style={styles.name}>{item.taskName ?? '读取中'}</Text>
            <Text style={styles.pct}>{pct}%</Text>
          </View>
        );
      }}
    />
  );
}
```

## 2.7 可运行验收

1. 登录后进入主界面，任务列表随服务器实时更新（新增/删除/进度变化）。
2. 转码中的任务进度条/百分比实时增长（dashboard timer 生效）。
3. 断开服务器网络 → store 标记掉线；恢复后自动重连 1 次。
4. 切后台 timer 暂停，回前台恢复（AppState 生效）。

> 若本步累了，可先合并到步骤 3 一起做，但**数据层（store + events + dashboard）宜先独立验证**，避免 UI 与数据 bug 混在一起难排查。
