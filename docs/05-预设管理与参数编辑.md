**替代方案**：自绘横向 `ScrollView` + 分段按钮同步（无原生动量，体验稍差）；`react-navigation` 的 material-top-tabs。

## 5.3 预设存储（对齐 appStore）

FFBox 用 `nodeBridge.localStorage`（electron-store）存 `presets.{name}`。FFa0x 用 AsyncStorage，key 结构保持一致：

```ts
// src/common/presetStore.ts
const KEY = "presets";
export async function getPresetList(): Promise<Preset[]> {
  const raw = await AsyncStorage.getItem(KEY);
  return raw ? JSON.parse(raw) : [];
}
export async function savePreset(name: string, params: OutputParams) {
  const list = await getPresetList();
  const secure = name.replaceAll(".", "．");
  const idx = list.findIndex(p => p.name === secure);
  if (idx >= 0) list[idx] = { name: secure, params };
  else list.push({ name: secure, params });
  await AsyncStorage.setItem(KEY, JSON.stringify(list));
  appStore.availablePresets = list.map(p => p.name);
}
export async function deletePreset(name: string) { /* 同理删除 */ }
```

**「默认配置」**：对应 FFBox 的 `defaultParams`，FFa0x 作为一个只读预设项（选中即加载默认参数）。

## 5.5 编辑预设页（`preset-edit.tsx`）

```
[返回]  编辑预设  [保存]
预设名输入框
ffmpeg 参数预览（globalParamsText）
[输入] [视频] [音频] [封装]   ← 左右滑动标签页
```

### 5.5.1 标题栏 + 草稿模型

- 进入编辑页时，从 `params` 深拷贝一份**草稿** `draftParams`。
- 所有参数修改只改 `draftParams`。
- 点「保存」→ `savePreset(name, draftParams)`。
- 点「返回」→ 丢弃草稿（不保存）。

```ts
const [draft, setDraft] = useState(() => JSON.parse(JSON.stringify(params)));
const preview = useMemo(() => getFFmpegParaArray({ outputParams: draft }).join(" "), [draft]);
```

> 区别于 FFBox：**不调用 `applyParameters`/`setParameters`**，因此不影响任何任务。

### 5.5.2 参数设置区

- 参考 `ParaBox`：`InputView.tsx`（输入）、`VcodecView.tsx`（视频）、`AcodecView.tsx`（音频）、`MuxView.tsx`（封装）。
- **「输入」标签**：FFBox 有文件列表，FFa0x **不实现**，文件列表永远是添加任务时选的唯一文件；只展示「硬件解码、跳过帧、读取速度」等参数（`InputFile` 的 hwaccel/skipFrame/readrate/detail/custom）。

### 5.5.3 参数控件示例

```tsx
// 视频标签：编码器下拉 + 码率滑块
<Dropdown
  items={vcodecItems}
  value={draft.outputs[0].video.vcodec}
  onChange={v => patch("outputs[0].video.vcodec", v)}
/>
<Slider
  min={0} max={8000}
  value={detail.crf ?? 0}
  onValueChange={v => patch("outputs[0].video.detail.crf", Math.round(v))}
/>
```

### 5.5.4 `getFFmpegParaArray` 精简移植

从 `@common/getFFmpegParaArray.ts` 移植，**只保留 FFa0x 需要的子集**：
- 不实现滤镜图（`filter` 恒为空）。
- 单输入单输出。
- 保留 `getInputFFmpegParam` / `getVideoFFmpegParam` / `getAudioFFmpegParam` / `getMuxFFmpegParam` 的核心逻辑（这些依赖 `builtInVcodecs/Acodecs/Muxers` 与 `RateControl` 结构）。

> 这是本步最大的工作量。建议先移植「默认预设」能跑通，再逐步补全各编码器/参数。未覆盖的编码器参数项留 TODO，预览处显示「（部分参数未支持）」，避免崩溃。

---

## 5.6 无「应用参数到全部输入/任务」

按需求 **不实现** `applyParameters('applyToAllTasks')` 与「应用到全部输入」。编辑预设只影响预设本身。

## 5.7 可运行验收

1. 主界面右下角「预设管理」按钮进入预设列表，能看到/新建/删除预设。
2. 任务条「选择预设」进入选择模式，点预设后应用到 run（未运行改当前 run，运行后建新 run）。
3. 编辑预设：改视频编码/码率，ffmpeg 参数预览实时更新。
4. 点「保存」后预设持久化（重启仍在）；点「返回」不保存。
5. 编辑预设不影响任何现有任务。
6. 未实现参数项显示占位，不崩溃。
