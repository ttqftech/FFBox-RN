**开始/暂停逻辑**（`ActionBar.handleStart` + `appStore.startNpause`）：

```ts
startNpause() {
  const e = this.currentServer?.entity;
  if (!e || e.status !== ServiceBridgeStatus.Connected) return;
  if (this.currentServer!.data.workingStatus === 'idle') e.queueStart();
  else e.queuePause();
}
```

## 3.4 多选模式

- 状态：`selectedTask: Set<number>`，`undefined` 表示非选择模式。
- 点「多选」→ 进入选择模式，按钮变「反选」。
- 选择模式下点击任务=切换选中，不进入详情。
- 点「反选」→ 取反（需 `fetchAllTaskIds` 拿全部 id，参考 `ActionBar.handleSelectAllClick`）；若数量为 0 退出选择模式。

```ts
// appStore
toggleMultiSelect() { this.multiSelect = this.multiSelect ? undefined : new Set(); }
invertSelection() {
  this.fetchAllTaskIds().then(ids => {
    const all = new Set(ids);
    for (const id of all) if (this.selectedTask.has(id)) all.delete(id);
    this.selectedTask = all;
    if (this.selectedTask.size === 0) this.multiSelect = undefined;
  });
}
```

> 说明：这里用 `multiSelect` 字段表示「是否在选择模式」。也可直接用「`selectedTask` 为 undefined」表示非选择模式，二选一，保持一致即可。

## 3.6 任务列表 TaskItem

参考 `TaskItem.tsx`，但精简为移动端两行布局：

- 第一行：状态图标 + 任务 id + 任务名 + 进度百分比
- 第二行：输出大小、`graphTime`、`graphSpeed`、`graphLeftTime`
- 整个任务条用 `backgroundProgress` 展示进度（绿/黄/灰/红/蓝）
- 左滑露出两个操作按钮：选择预设、暂停/重置/删除
- 非选择模式点击 → 进详情页

```tsx
// src/components/TaskItem.tsx（核心）
export function TaskItem({ task, index, onPress }: Props) {
  const snap = useSnapshot(appStore);
  const run = task.runs[task.selectedRunIndex];
  const d = run?.dashboard_smooth ?? { progress: 0, bitrate: 0, speed: 0, time: 0, frame: 0, size: 0 };
  const pct = Math.round(d.progress * 100);
  return (
    <ReanimatedSwipeable renderRightActions={renderActions}>
      <Pressable style={styles.task} onPress={onPress}>
        <View style={[styles.progressBar, { width: `${pct}%` }]} />
        <View style={styles.row1}>
          <StatusIcon status={task.status} />
          <Text style={styles.id}>{task.id}</Text>
          <Text style={styles.name} numberOfLines={1}>{task.taskName ?? '读取中'}</Text>
          <Text style={styles.pct}>{pct}%</Text>
        </View>
        <View style={styles.row2}>
          <Text>{formatUtils.size(d.size)}</Text>
          <Text>{formatUtils.time(d.time)}</Text>
          <Text>{formatSpeed(d.speed)}</Text>
          <Text>{formatLeftTime(d)}</Text>
        </View>
      </Pressable>
    </ReanimatedSwipeable>
  );
}
```

**状态图标**（`taskStatusIcon`）：`TaskStatus` → 图标映射（initializing/idle/idle_queued/running/paused/paused_queued/stopping/finished/error）。

**选择预设按钮的可用性**（参考 `appStore.applyParameters` 判断）：
- 未运行（idle/error/finished）→ 点击后选择预设**修改当前 run**
- 运行中（running/paused…）→ 不可点击
- 运行后（finished/error）→ 点击后选择预设**创建新 run**

**暂停/重置/删除按钮**（`TaskItem.handlePauseNremove`）：
- running/paused_queued → `taskPause`
- idle_queued/paused/stopping/finished/error → `taskReset`
- idle/initializing → `deleteTasks`

## 3.7 掉线处理

- 掉线时**任务列表隐藏**，居中显示掉线面板 + 重试按钮（参考 `MainArea.vue` 的 disconnectArea）。
- 复活时自动重连 1 次。
- 事件总线用 npm `events`（见步骤 2）；自动重连标记放在 ServiceBridge 实体层（`reconnectAttempted`），手动断开不重连，仅意外掉线自动重连 1 次。

```tsx
// 主界面
const status = snap.currentServer?.entity.status;
if (status === ServiceBridgeStatus.Disconnected || status === ServiceBridgeStatus.Reconnecting) {
  return <DisconnectPanel onRetry={() => appStore.reConnectServer(id)} />;
}
```
