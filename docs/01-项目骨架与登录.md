# 步骤 1：项目骨架与登录连接

> 目标：App 能启动，有登录页（IP/端口/用户名/密码 4 框 + 最近使用列表），点「连接」能成功连上 FFBox 服务端并进入一个可运行的主界面占位页。**本步不做真实任务数据，主界面只放占位。**

## 1.2 库选型

### 1.2.1 导航：`expo-router`（已装）

**使用理由**：项目已初始化 expo-router，文件即路由，与原生导航栈体验一致，无需额外配置。

```tsx
// src/app/_layout.tsx
import { Stack } from 'expo-router';
export default function RootLayout() {
  return (
    <Stack screenOptions={{ headerShown: false }}>
      <Stack.Screen name="index" />
      <Stack.Screen name="(main)" />
    </Stack>
  );
}
```

**替代方案**：`react-navigation`（expo-router 底层就是它，但配置更繁琐）。

### 1.2.2 本地存储：`@react-native-async-storage/async-storage`

**使用理由**：存「最近使用服务器」列表和后续的「预设」，轻量、官方生态、跨平台一致。

```bash
pnpm exec expo install @react-native-async-storage/async-storage
```

```ts
// src/common/storage.ts
import AsyncStorage from '@react-native-async-storage/async-storage';

export interface ServerInfo {
  ip: string; port: string; username: string; password: string;
}
export async function getServersInfo(): Promise<ServerInfo[]> {
  const raw = await AsyncStorage.getItem('serversInfo');
  return raw ? JSON.parse(raw) : [];
}
export async function saveServersInfo(list: ServerInfo[]) {
  await AsyncStorage.setItem('serversInfo', JSON.stringify(list));
}
```

**替代方案**：`expo-sqlite`（结构化更强但对本场景过重）。

### 1.2.3 连接测试：`fetch` + 内置 `WebSocket`（零依赖）

**理由**：RN 的 `fetch`/`WebSocket` 与 Web 一致，serviceBridge 可移植。本步先写一个「最小连接函数」验证链路，完整 ServiceBridge 留到步骤 2。

```ts
// src/bridges/minConnect.ts（本步临时，步骤2由 serviceBridge 取代）
export async function testConnect(ip, port, username, password) {
  const base = `http://${ip}:${port}`;
  const ver = await fetch(`${base}/api/v1/system/version`).then(r => r.text());
  const login = await fetch(`${base}/api/v1/auth/login`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ username, passkey: sha256(password) }),
  }).then(r => r.json());
  if (!login.isSuccess) throw new Error('用户名或密码错误');
  return { version: ver, sessionId: login.sessionId, permissions: login.permissions };
}
```

**替代方案**：`reconnecting-websocket`（步骤 2 掉线重连时可引入）。

### 1.2.4 密码哈希：`expo-crypto`

**理由**：登录用 `SHA256(password)`，`expo-crypto` 原生实现、快、无重依赖。

```bash
pnpm exec expo install expo-crypto
```

```ts
import * as Crypto from 'expo-crypto';
const passkey = await Crypto.digestStringAsync(Crypto.CryptoDigestAlgorithm.SHA256, password);
```

**替代方案**：`crypto-js`（纯 JS，慢但兼容 FFBox 用法）。

## 1.3 登录页实现

参考 `src/renderer/src/App/MainFrame/MainArea/MainArea.vue` 的登录区（4 框 + 连接按钮），但最近使用列表**固定在画面下方**，不做弹出下拉。

```tsx
// src/app/index.tsx（骨架）
import { useState } from 'react';
import { View, Text, TextInput, TouchableOpacity, FlatList, StyleSheet } from 'react-native';
import { getServersInfo, saveServersInfo, ServerInfo } from '../common/storage';

export default function LoginScreen({ navigation }: any) {
  const [ip, setIp] = useState('127.0.0.1');
  const [port, setPort] = useState('33269');
  const [username, setUsername] = useState('');
  const [password, setPassword] = useState('');
  const [recent, setRecent] = useState<ServerInfo[]>([]);
  const [connecting, setConnecting] = useState(false);

  const refreshRecent = async () => setRecent(await getServersInfo());

  const handleConnect = async () => {
    setConnecting(true);
    try {
      await testConnect(ip, port, username, password);
      // 保存/更新最近使用
      const list = await getServersInfo();
      const idx = list.findIndex(s => s.ip === ip && s.port === port && s.username === username);
      const info = { ip, port, username, password };
      if (idx >= 0) list[idx] = info; else list.push(info);
      await saveServersInfo(list);
      navigation.replace('main');
    } catch (e: any) {
      alert('连接失败：' + e.message);
    } finally {
      setConnecting(false);
    }
  };

  const removeRecent = async (item: ServerInfo) => {
    await saveServersInfo(recent.filter(s => !(s.ip === item.ip && s.port === item.port && s.username === item.username)));
    refreshRecent();
  };

  return (
    <View style={styles.container}>
      <Text style={styles.title}>连接服务器</Text>
      <TextInput placeholder="IP" value={ip} onChangeText={setIp} style={styles.input} />
      <TextInput placeholder="端口" value={port} onChangeText={setPort} style={styles.input} keyboardType="number-pad" />
      <TextInput placeholder="用户名" value={username} onChangeText={setUsername} style={styles.input} />
      <TextInput placeholder="密码" value={password} onChangeText={setPassword} style={styles.input} secureTextEntry />
      <TouchableOpacity disabled={connecting} onPress={handleConnect} style={styles.button}>
        <Text style={styles.buttonText}>{connecting ? '连接中…' : '连接'}</Text>
      </TouchableOpacity>

      <Text style={styles.section}>最近使用</Text>
      <FlatList
        data={recent}
        keyExtractor={(_, i) => String(i)}
        renderItem={({ item }) => (
          <View style={styles.recentRow}>
            <TouchableOpacity style={{ flex: 1 }} onPress={() => { setIp(item.ip); setPort(item.port); setUsername(item.username); setPassword(item.password); }}>
              <Text>{item.ip}:{item.port}{item.username ? `@${item.username}` : ''}</Text>
            </TouchableOpacity>
            <TouchableOpacity onPress={() => removeRecent(item)}><Text>✕</Text></TouchableOpacity>
          </View>
        )}
      />
    </View>
  );
}
```

> 主界面占位：`src/app/(main)/index.tsx` 放一个「主界面（待实现）」文本即可，保证跳转后不崩溃。

## 1.4 网络权限配置（Android）

FFBox 服务端常用裸 http，Android 需允许明文流量。

```jsonc
// app.json
"android": {
  "usesCleartextTraffic": true,
  "permissions": ["READ_EXTERNAL_STORAGE", "WRITE_EXTERNAL_STORAGE"]
}
```

> 具体权限（存储/媒体）在步骤 6 下载时再完善，本步先配明文流量。

## 1.5 可运行验收

1. `pnpm exec expo start` 启动，登录页可见 4 输入框 + 连接按钮 + 最近使用列表。
2. 输入一个真实 FFBox 服务端地址，点「连接」，成功则跳转主界面占位页。
3. 连接成功后，该条记录出现在「最近使用」列表；点列表项回填输入框；点 ✕ 能删除。
4. 输入错误密码，提示「密码错误」且不跳转、不崩溃。
